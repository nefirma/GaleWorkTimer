# GaleWorkTimer — инструкция для Гали

## Постоянная установка и обновление — кандидат T-2

**Этот кандидат пока не опубликован и не проверен на Windows.** Используй его только после того, как команда передаст оба файла: `GaleWorkTimer.Setup.exe` и `GaleWorkTimer-win-x64.zip`.

### Первый переход со старого portable ZIP

1. Закрой запущенный GaleWorkTimer через **Exit** или крестик. Не удаляй старую portable-папку и не перемещай базу.
2. Запусти `GaleWorkTimer.Setup.exe`. Установщик работает для текущего пользователя; administrator rights и отдельный .NET runtime не нужны.
3. В окне выбора файла укажи `GaleWorkTimer-win-x64.zip` и подтверди выбор.
4. Установщик проверит пакет и установит приложение в `%LOCALAPPDATA%\Programs\GaleWorkTimer`.
5. Для запуска используй `%LOCALAPPDATA%\Programs\GaleWorkTimer\GaleWorkTimer.exe`. Создай ярлык на этот путь один раз; ярлыки на старую portable-папку автоматически не меняются.

Старая portable-папка и её файлы не меняются. Установщик не открывает и не переносит базу. Приложение продолжает использовать `%LOCALAPPDATA%\NeFirma\GaleWorkTimer\data.db` и соседние SQLite-файлы.

### Обычное обновление

1. Сначала закрой GaleWorkTimer. Установщик не завершает процессы принудительно.
2. Запусти переданный `GaleWorkTimer.Setup.exe`, выбери новый ZIP и дождись сообщения об установленной версии.
3. Запускай приложение по тому же стабильному пути. Старый payload сохраняется для отката; каталоги выпусков не накапливаются.
4. Если установщик сообщает о занятом файле, закрой приложение и повтори попытку. Не удаляй файлы из install-root вручную.

### Если обновление прервалось

При следующем запуске через стабильный `GaleWorkTimer.exe` recovery сначала проверит состояние, выберет предыдущий полный payload и покажет код этапа с понятной причиной. В окне сообщения нажми **Ctrl+C**, чтобы скопировать текст и передать его команде. Непроверенный или частичный payload не запускается.

При неудаче первой установки предыдущей версии нет: частичный payload не запускается; снова запусти `GaleWorkTimer.Setup.exe` и выбери ZIP. Не считай сообщение об успешной распаковке доказательством установки: успех означает, что проверенный payload выбран для стабильного запуска.

Сохранность Windows locking, ярлыков, кириллицы/пробелов в пути и реальный запуск на Windows ещё не подтверждены. До отдельной проверки Гали W1–W4 остаются `NOT_YET_PROVEN`.

## Текущая публичная Windows 11 x64 — T2.5 Preview (portable ZIP)

1. Закрой старую версию через **Exit** или крестик окна. Не запускай одновременно
   старую и новую версии: защита от второго экземпляра пока не реализована.
2. Скачай **GaleWorkTimer-T2.5-win-x64.zip** со страницы
   https://github.com/nefirma/GaleWorkTimer/releases/tag/t2.5-preview
3. Распакуй **весь ZIP** в отдельную папку, например `GaleWorkTimer-T2.5`.
4. Запусти **GaleWorkTimer.exe** из этой папки. Не переноси только EXE — рядом
   должны остаться DLL, runtime и остальные файлы архива.

Установщик и отдельная установка .NET не нужны.

### Что будет с существующими данными

Программа использует ту же базу, что T2.3/T2.4:

`%LOCALAPPDATA%\NeFirma\GaleWorkTimer\data.db`

Чтобы открыть папку данных, нажми **Win+R**, введи
`%LOCALAPPDATA%\NeFirma\GaleWorkTimer` и нажми Enter.

**Не удаляй базу и не заменяй её при обновлении программы.** Папка программы
и папка данных — разные места. В ZIP нет чужой базы. При первом запуске,
если базы нет, программа создаст её. Версия схемы остаётся 2, миграция не нужна.

## Что нового в T2.5

- **Калькулятор «Общее время».** Отметь флажками слева несколько Timer на вкладке
  **Timers** и нажми **Общее время** сверху. Рядом появится сумма накопленного
  активного времени выбранных Timer в формате **HH:MM**, например `02:05` или
  `126:15`. Паузы не считаются, часы после 24 не сбрасываются. Время разных
  одновременно работавших Timer складывается независимо.
  Можно выбрать Stopped, Paused и Running. Для Archived Timer сначала нажми
  **Restore to list**. Без выбора результат — `00:00`.
  Калькулятор использует текущий снимок Total и сам не обновляет время:
  если нужен свежий снимок, нажми **Refresh**, проверь флажки и рассчитай снова.
  При изменении выбора или обновлении списка прежняя сумма скрывается;
  проверь выбор и снова нажми **Общее время**. Выбор не сохраняется после выхода.
- **Новые Timer сверху.** Порядок зависит от времени создания, а не от последнего
  запуска, Edit или Restore. При одинаковом времени создания более новый ID идёт
  первым. В Archived timers действует тот же порядок.
- **Копирование имени одним нажатием.** Справа от цветного имени есть маленькая
  кнопка с двумя перекрывающимися прямоугольниками — стандартная Copy icon.
  При наведении появляется **Copy name**. Нажми её, затем **Ctrl+V** в нужном
  текстовом поле: вставится только имя Timer, без статуса и Total.
  Кнопка также есть у Archived Timer. Выделять текст не нужно.
- Если копирование не удалось, в окне появится сообщение об ошибке.
  Отдельного уведомления об успешном копировании нет — это нормально.

## Основные действия

- Введи **Name**, выбери цвет и нажми **+ Add timer**.
- **Start** — начать Session. Можно одновременно запустить несколько Timer.
- **Pause** — приостановить учёт активной работы; **Resume** — продолжить.
- **Stop** — закончить текущую Session.
- **Edit** — изменить имя и цвет, сохранив историю.

Цветной заголовок обозначает сам Timer. Цвет статуса имеет отдельный смысл:
**Stopped** — красный, **Paused** — янтарный, **Running** — зелёный.

**Total** — сумма активной работы всех Sessions данного Timer, без пауз.
Это статический снимок: он не тикает каждую секунду. Для обновления нажми
**Refresh** на вкладке Timers; действия Start/Pause/Resume/Stop также обновляют
снимок. Время показывается до целых минут с округлением вниз, поэтому короткая
работа может пока отображаться как `0 min`.

Вкладка **History** показывает отдельные Sessions, новые сверху. Её **Refresh**
обновляет только снимок History. Редактирования отдельных Sessions пока нет.

## Убрать из списка или удалить навсегда

- **Remove from list** убирает Stopped Timer в **Archived timers**, сохраняя всю
  историю. **Restore to list** возвращает его в основной список.
- **Delete** необратимо удаляет Timer **и всю его историю**, включая Sessions
  и паузы. Кнопка доступна только для Stopped Timer, в том числе Archived.
  Running/Paused Timer сначала нужно явно остановить через **Stop**.
- Перед удалением появится предупреждение. **Cancel**, Escape или закрытие
  диалога отменяют удаление. Подтверждай **Delete** только если история не нужна.

## Закрытие программы

**Minimize** сворачивает обычное окно. Крестик или **Exit** полностью закрывают
программу, но **не останавливают Timer**. Если Timer оставался Running,
после открытия он учтёт время закрытой программы. Paused останется Paused.
Если работу нужно закончить, нажми **Stop** до выхода.

Tray, hotkeys, autostart, notifications, Statistics, CSV и auto-update пока нет.

## Быстрая проверка новой версии

1. Создай тестовые A, B, C и проверь порядок **C → B → A** выше старых Timer.
2. Нажми Copy у нужного Timer и вставь в текстовое поле: должно совпасть имя.
3. Отметь два или больше Timer, нажми **Общее время** и проверь сумму в `HH:MM`.
   Измени выбор и пересчитай. Сумма складывает исходные durations, а не округлённые
   до минут подписи: две короткие работы по 30 секунд вместе дают `00:01`.
4. Проверь, что старые Timer, Total и History сохранились после обновления.
5. Проверяй Delete только на ненужном тестовом Timer — восстановить его нельзя.

Сборка подготовлена и статически проверена на Linux. Работа именно T2.5
на Windows, включая системный буфер обмена и калькулятор, ещё требует ручной проверки.
